Core AI intelligent processing components including Agents-api REST interface, LLM Service integration for natural language log explanation and severity classification, RAG Connector for knowledge base retrieval, and Rule-Based Engine for alert validation and remediation suggestions.

**CVE scoring engine (2026-07-16):** keyword matching replaced with a BM25+IDF multi-signal scorer — vendor alias expansion (18 vendors), multi-field weighted scoring (CVE ID, vendor, product, description tokens, protocol/vuln-type co-occurrence), CVSS boost factor. Returns empty instead of noisy random fallback when no CVE scores ≥ 3.
